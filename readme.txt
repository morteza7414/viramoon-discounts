تعیین تخفیف درصدی یا مبلغ ثابت برای محصولات ساده و متغیر ووکامرس، با اعمال تکی و گروهی، زمان‌بندی و پیش‌نمایش قیمت.

== Description ==

افزونه تخفیف محصولات ویرامون تخفیف را از طریق فیلدهای استاندارد قیمت ووکامرس
(`_sale_price` و تاریخ‌های حراج) اعمال می‌کند تا قالب‌ها، کش قیمت و گزارش‌های
ووکامرس بدون تغییر کار کنند.

قابلیت‌ها:

* تخفیف درصدی یا مبلغ ثابت برای محصول ساده
* تخفیف مستقل برای هر Variation با زمان‌بندی جداگانه
* اعمال گروهی روی همه/انتخاب‌شده/بدون‌تخفیف Variationها با پیش‌نمایش و گزارش
* صفحه تخفیف گروهی روی فهرست محصولات با پردازش دسته‌ای (batch) و نوار پیشرفت
* زمان‌بندی با Action Scheduler ووکامرس (و WP-Cron به‌عنوان جایگزین)
* ثبت مالکیت تخفیف؛ حراج دستی یا افزونه دیگر بدون تأیید بازنویسی نمی‌شود
* کسر کارمزد درگاه پرداخت (اسنپ‌پی، دیجی‌پی و …) از تخفیف مشتری

== Installation ==

1. فایل ZIP را از مسیر «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
2. افزونه را فعال کنید.
3. از مسیر «ووکامرس ← تنظیمات ویرامون» تنظیمات را انجام دهید.
